# Drupify Website

Official website for Drupify, a Drupal-focused web development agency.

## Project Summary

This repository contains the Drupal codebase for the redesigned Drupify website. The redesign focuses on clearer service presentation, improved layout, responsive pages, and a stronger agency identity for Drupal development and support services.

## My Role

Drupal Developer / Project Manager / Team Lead

## Work Done

- Redesigned the official Drupify agency website.
- Improved service sections, layout, and content presentation.
- Built and adjusted Drupal theme templates and frontend styling.
- Supported responsive design improvements for desktop and mobile.
- Organized the project for local Drupal development with DDEV.
- Managed configuration workflow with Composer and Drush.
